# Panda Plush Co.

A single-file demo storefront for panda plushies. Open `index.html` in a browser, no build step or server needed.

- Home page with hero, departments, deals, popular categories, brands and recently viewed
- Browse view with department tree, price/size/colour/brand/stock filters, sort, grid/list toggle and pagination
- Search with autocomplete, product pages with specs, and a cart drawer with an order-request form, email and print/PDF
- 178 generated products; all panda artwork is drawn as inline SVG
- Cart and recently viewed are saved in `localStorage`; no payment or backend
